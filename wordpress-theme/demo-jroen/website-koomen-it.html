Bezoek website
koomen.it

De website waar je nu naar kijkt. Een eigen WordPress-thema in de huisstijl van koomen.it, gemaakt om embedded projecten en websites overzichtelijk te laten zien.

Wat erin zit

  • Twee eigen berichttypes, Projecten en Websites, met filters per platform en per websitetype.
  • Per project en website gegevens zoals status, jaar, technieken, hardware en links naar GitHub of de live site.
  • Een hero met een codevenster dat echte code uit een project intypt, met syntax-kleuring voor Python en C++.
  • Alle teksten, kleuren en secties van de homepage zijn aan te passen in de Customizer.

Het thema werkt zonder page builder of extra plugins, laadt alleen een klein script en is volledig responsive.
